# Sneaker Collector Project
My project is a sneaker collector that allows users to create, modify, and remove sneakers along with their prices to build the best collection.
## Features
___
Add - Add your own sneakers to the collection
Remove - Remove sneakers you please
Print - Prints the entire vault 
Search - Search for a shoe by certain parameters
Filter by Brand - Filter your list by brand
Wear a Shoe Once - Wears a shoe once, lowers the resale price by a tiny bit and sets deadstock to false
Return Deadstock Shoes - Returns all shoes in the list that are deadstock
Print Stock Price - Prints the stock price of entire vault
Print Resale Price - Prints the resale price of entire vault
Set Resale Price - Sets the resale price of a selected shoe
