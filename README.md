# Sneaker Collector Project
My project is a sneaker collector that allows users to create, modify, and remove sneakers along with their prices to build the best collection.
## Features
1. Add - Add your own sneakers to the collection
2. Remove - Remove sneakers you please
3. Print - Prints the entire vault 
4. Search - Search for a shoe by certain parameters
5. Filter by Brand - Filter your list by brand
6. Wear a Shoe Once - Wears a shoe once, lowers the resale price by a tiny bit and sets deadstock to false
7. Return Deadstock Shoes - Returns all shoes in the list that are deadstock
8. Print Stock Price - Prints the stock price of entire vault
9. Print Resale Price - Prints the resale price of entire vault
10. Set Resale Price - Sets the resale price of a selected shoe
